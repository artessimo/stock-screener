# 日本大型株「買い検討」候補ログ

プロ視点のスクリーニング候補を日付ごとに記録し、事後検証（PDCA）できるようにする。

- **最終判断はユーザー自身**（投資助言ではない）
- 対象：TOPIX100 / 日経225 / 時価総額おおむね1兆円以上
- 観点：テクニカル（売られすぎ・反発）／ファンダ（PER・PBR・配当・業績）／材料（決算・テーマ）
- 保有期間（タイプ別）: **A** テクニカル2〜3ヶ月（内需安定のみ） / **B** バリュー・テーマ3〜6ヶ月 / **C** 急騰テーマ・海外センチメント〜3ヶ月（半分利確）
- 候補と約定は分ける。各候補に **買い帯 / 無効化 / 追禁止** を付ける
- 実弾は **2026-09-25夜から運用約2,400万円**（400万円＋追加現金約2,000万円）。同時最大10スロット（1銘柄＝1ファクター）。1銘柄150〜250万円、現金約400〜500万円は帯待ち。余力は追買い理由にしない。損切到達後のナンピン禁止

## ファイル

| ファイル | 内容 |
|---|---|
| `pdca-log.csv` | 判定ログ（コピー用フォーマット互換） |
| `improved-screening-prompt.md` | 敗因学習後の改善版選定プロンプト |
| `retrospectives/` | 基準日バックテストと実弾ロジック振り返り |

## 使い方

1. 判定日に `pdca-log.csv` へ **候補** 行を追加（状態が分かるメモを `notes` に残す）
2. 買い帯で約定したら別メモで約定行を確定する。ウォッチ帯の外では追わない
3. 決済後に `result_pct` / `hit` / `notes` を更新
4. ヒット率・平均リターン・スクリーニング改善点を振り返る（損切幅は1件の負けで緩めない）
